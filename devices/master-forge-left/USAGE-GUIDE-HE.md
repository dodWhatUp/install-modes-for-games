# Master Forge left — מדריך שימוש ותפעול

מעמד: מדריך שימוש למיפוי הקיים. הוא אינו משנה את המפה או את הגדרות המכשיר.

## כיוונים ביחס ליד שמאל

- **למעלה** — לכיוון קצות האצבעות, הרחק משורש כף היד.
- **למטה** — לכיוון שורש כף היד.
- **פנימה** — לכיוון האגודל / מרכז היד.
- **החוצה** — לכיוון הזרת / מחוץ ליד.

הלחיצה האנכית פנימה על מתג ה־Master Forge אינה "מקש חמישי": לפי המיפוי/תיעוד שנבדק היא מפעילה את ארבעת הכיוונים יחד.

## Profiles

- **A** — פרופיל ההקלדה/CharaChorder המקורי שנשמר.
- **B** — פרופיל משחקים ליד שמאל.
- **C** — מקלדת מלאה ביד שמאל, עכבר, ניווט וקיצורים.

בחירת A/B/C בראש ה־Device Manager בוחרת את יעד העריכה. מעבר בזמן שימוש נעשה בעזרת פעולות Profile במפה.

### מעבר בין Profiles

- **A → B:** אצבע + אמה + קמיצה **למטה יחד**, ואז שחרור יחד. במפת A זה chord של `E+O+U → Profile B`.
- **B → A:** להחזיק זרת **החוצה** כדי להיכנס ל־B2, ואז Aux1 **פנימה**.
- **B → C:** להחזיק זרת **החוצה**, ואז אצבע **פנימה**.
- **C → B:** להיכנס ל־C3, להחזיק Mirror (אגודל תחתון **החוצה**), ואז קמיצה **פנימה**.
- **C → A:** להיכנס ל־C3, להחזיק Mirror, ואז קמיצה **למעלה**.

### תצפית פיזית חדשה — 2026-09-24

המשתמש דיווח שהמעבר **A → B** באמצעות אצבע+אמה+קמיצה למטה מצליח רק בחלק מהניסיונות. זו תצפית שימוש אמיתית, אך הסיבה **לא הוכחה**. לפני שינוי המפה יש לבדוק:

1. שב־A כל אחד משלושת הכיוונים בנפרד מפיק `E`, `O`, `U`.
2. שהשלושה נלחצים ומשתחררים בתוך חלונות ה־Chording **Press Tolerance / Release Tolerance**.
3. האם שינוי tolerance משפר אמינות בלי לפגוע בהקלדה.
4. אם עדיין לא אמין, לשקול בעתיד מעבר Profile על מקש יחיד או chord פשוט יותר — רק לפי בקשה מפורשת.

## Layers

### Profile B — משחקים

- **B1** — שכבת המשחק הראשית.
- זרת **החוצה** = החזקת **B2**.
- שחרור הזרת = חזרה אוטומטית ל־B1.
- האגודל העליון: למעלה=W, פנימה=D, למטה=S, החוצה=A.
- ב־B ה־Chording כבוי; המכשיר מוגדר ל־12-key rollover. זה מאפשר החזקת מקשי מקלדת רגילים במקביל, אך אינו מוכיח ששני כיוונים סמוכים באותו מתג רב־כיווני נוחים/אמינים יחד.

### Profile C — שימוש מלא ביד שמאל

- **C1** — אותיות ועריכה בסיסית.
- זרת **החוצה** — החזקת **C2** (מספרים/סימנים); שחרור מחזיר ל־C1.
- זרת **למעלה** — מעבר ל־**C3** (עכבר/Windows/ניווט), שנשאר עד מעבר חזרה.
- זרת **פנימה** — מעבר ל־**C4** (F1–F12 ופונקציות), שנשאר עד מעבר חזרה.
- אגודל תחתון **החוצה** — **Mirror**, כלומר הבנק המשלים של היד.

## שמות שימושיים ב־Configurator

- **Primary Keymap** — שכבה ראשית.
- **Numeric Layer** — שכבה שנייה.
- **Function Layer** — שכבה שלישית.
- **Profile A / Profile B / Profile C** — מעבר Profile בזמן שימוש.
- **Ambidextrous Throwover** — Mirror / שימוש בבנק של היד הנגדית.
- **Spurring Toggle** — מצב chording ייעודי; אינו מופעל כפתרון למעבר Profile הנוכחי.
- **Toggle Generative Text Menu** — פתיחת GTM.

## יכולות דומות ל־QMK

| צורך | Master Forge / CCOS |
|---|---|
| כמה מקשים רגילים במקביל | כן, בכפוף ל־rollover ולחומרה |
| כמה inputs → פעולה אחת | Chord |
| שכבה בזמן החזקה | כן |
| שכבה שנשארת פעילה | כן |
| Mirror ליד אחת | Ambidextrous Throwover |
| Macros | כן |
| Mouse keys | כן |
| פעולה שונה ב־flick מהיר | Quick Flick קיים ב־CCOS, אך אינו Tap Dance כללי |
| שינוי held keys במעבר שכבה | Layer Warp קיים; כרגע כבוי ב־B |
| Tap קצר=X / Hold=Y כמו QMK Mod-Tap | לא מוגדר כך במפה הנוכחית ולא אומת כמנגנון כללי מקביל |
| Single/Double/Triple Tap כללי כמו Tap Dance | לא אומתה מקבילה כללית מלאה |

במפה הנוכחית של B, זרת החוצה היא מקש layer ייעודי ו־V נמצא בזרת למטה; אין tap=V / hold=B2.

## שני כיוונים סמוכים באותו מתג

ה־Master Forge מציג ארבעה כיוונים דיגיטליים לכל מתג. לא נשמרה ראיה שהחומרה מספקת מצב 8-way עצמאי עם NW/NE/SW/SE כארבעה inputs נפרדים.

לכן יש להבדיל בין:
- **שני מקשים שונים במקביל** — נתמך במפת המשחק.
- **שני כיוונים סמוכים באותו מתג פיזי** — עדיין דורש בדיקה פיזית.

בדיקה מומלצת לאגודל העליון: לנסות למעלה+החוצה, למעלה+פנימה, למטה+החוצה, למטה+פנימה ולראות אם שני הקודים נשארים לחוצים באופן יציב. **NOT_RUN** כרגע.

אם האלכסונים אינם אמינים ובמשחק נדרשים 8 כיווני תנועה, הפתרון הבטוח יותר הוא לפצל את שני צירי התנועה בין שני מתגים פיזיים, כך שהאלכסון נוצר משני switches נפרדים. זה רעיון להמשך בלבד; המיפוי לא שונה.
