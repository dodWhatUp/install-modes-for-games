## Split files in Drive

The Drive connector accepts files smaller than 100 MiB. Larger archives, and four archives rejected by the connector's intermediate file cache, are stored as byte-identical `.part001`, `.part002`, and later parts. Rebuild a file in PowerShell from a folder containing all of its parts:

```powershell
$output = 'SkyrimUpscalerAIOBuild19-Hotfix1.zip'
$parts = Get-ChildItem -File "$output.part*" | Sort-Object Name
$destination = [System.IO.File]::Create((Join-Path $PWD $output))
try {
    foreach ($part in $parts) {
        $source = [System.IO.File]::OpenRead($part.FullName)
        try { $source.CopyTo($destination) } finally { $source.Dispose() }
    }
} finally { $destination.Dispose() }
Get-FileHash -Algorithm SHA256 -LiteralPath $output
```

Compare the rebuilt hash with the manifest before extraction. The local original archives were not modified by splitting.

## Skyrim release notes and boundary

The current official package is `SkyrimUpscalerAIOBuild19-Hotfix1.zip` from the `skyrim-downloads` forum. Build 19 includes PD FrameWarp, improved first-person handling and edge treatment, multi-pass DLSS NR controls, in-game quality selection, and fixes for FrameWarp stutter/camera jumps and Community Shaders interactions. Hotfix 1 adds RTSS compatibility detection, fixes controller judder, and requires ReShade 6.8.0 with full add-on support when ReShade is used.

The package defaults to DLSS upscaling and DLSS frame generation, exposes RTX 50 Dynamic MFG, and sets PD FrameWarp to first-person mode. It is an SKSE plugin. Installation remains gated on official SKSE64 2.3.1 for Steam runtime 1.7.104; the Nexus guest session cannot download it. No unsupported SKSE substitute or automatic game downgrade is allowed.
