How to use the Azeron layers and shared actions

#19: hold to show Overlay. #2: hold WEAPONS; release returns. #1 MENUS, #28 NAV, #36 TOOLS and #30 SYMBOLS also remain momentary. Movement stays on #24; Ctrl #5, Shift #9 and Space #14 are preserved.

Tap L for Quick Switch; hold for the Weapon Wheel (180 ms delay). K is Shield Throw or Meat Hook / Spear Ready according to weapon/context. Ready, Orbit and Block use press-and-hold; keyboard Stab and Slam use Single Input. G switches the off-hand weapon; H switches the class weapon. These are separate actions.

Ready #10 and Slam #9 share the middle finger; Jump #14 and held Wheel #15 share the index finger. Use Mouse3 for Ready when the combination is awkward, and #2 + the numeric weapon grid to avoid holding Wheel. Physical reach and combat behavior still need your play check.

The default Overlay context is gameplay. The saved menus / AutoMap / Atlan / Dragon contexts can be selected in Game Tools; engine-context detection was not verified. Turret has no separate published context in this existing map family.

Menu details, file ownership and recovery
  • Slayer repeats Next Melee Weapon and Next Shield Rune in Misc; the duplicate rows share the same binding.
  • The native Weapons menu shows 1–6 and 9. Existing Azeron 7/8 outputs are retained, but have no separate row here.
  • Menu confirmation/back and Pause are fixed controls outside the editable rows: Space/Enter confirm; Esc back/pause; Tab also backs out according to CFG.
  • Other input tabs retain their existing effective bindings. In these tabs Dossier is Tab and Objective Ping is H.
  • Four selectors are stored in the opaque native game profile and are absent from the text CFG; do not invent CFG commands for them.

The seven registered CFG row changes were applied with the existing guarded binding service. The game’s native profile also needed menu edits; four selectors exist only there. A CFG replacement alone cannot reproduce all ten changes. Fresh pre-change and final backups are kept privately with verified hashes. Restore requires a reviewed, paired game-profile and CFG operation while DOOM and Steam are closed.
