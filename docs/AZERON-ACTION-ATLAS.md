# Azeron Action Atlas — existing toolkit module

Current authored work: [R7 research, source and evidence](../research_outputs/input-controls/azeron-keybinds/r7/README.md).
Read [the module plan](../research_outputs/input-controls/azeron-keybinds/r7/ACTION_ATLAS_PLAN.md), [game onboarding](../research_outputs/input-controls/azeron-keybinds/r7/GAME_ONBOARDING.md) and [continuity](../research_outputs/input-controls/azeron-keybinds/r7/CONTINUITY_R7.md).

This extends the keymap gate of [the shared game-tools architecture](GAME-TOOLS-ARCHITECTURE.md) and the existing [knowledge index](GAME-TOOLS-KNOWLEDGE-INDEX.md), [Hub](../examples/game-tool-hub/README.md), [Studio integration](../examples/game-input/OVERLAY-STUDIO-INTEGRATION.md) and [schema-2 mapping contract](../templates/GAME-KEYBINDS.example.json). It is not a separate remapper, task queue, universal shell executor or new personal-system project.

Implemented: a self-contained manual HTML view with optional action icons/category colors, Keys/Actions/Combined, context/category filters, cross-layer search, source details and stable native button geometry. Eight publisher/project sample sets contain 179 scoped action records; ten requested title/family targets remain explicitly pending. R6 COMPACT4/SPARSE5 native outputs remain unchanged. Only source/logic checks have passed; no browser/host/game acceptance is claimed.

Future: non-focus-stealing held Peek versus explicitly pinned Explore; an optional validated snapshot adapter to the existing Studio/Hub; supported fresh native layer observation; optional executable-to-label associations and links to prepared toolkit recipes. A label or icon click never authorizes an input/action. No hook, listener, profile change or automatic execution is installed by this proposal.

Hard requirements: #19 reserved/unassigned/hidden without an invented trigger; joystick drawing omitted without changing its input; all other 29 digital slots, including #36/#37, retained; MENUS naming and each family's source-derived blank masks preserved; color/icon always accompanied by text or other redundant meaning; unknown/effective/default evidence kept distinct.

Use the existing private Azeron Drive folder and recovery index for generated delivery views and native backups. R7's publication receipt identifies its exact source head and private artifacts. Preserve all later live R5/R6 work and unrelated branches. Research, publication, import, physical comfort and gameplay verification are separate states.
