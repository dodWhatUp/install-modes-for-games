What AI can work with

Ordered mod plans, existing download/staging jobs, selected saved report summaries, explicitly shared stock-tool status, and existing overlay group selection. Old keyboard shortcuts are isolated from these pages. Modern/Classic views keep the same underlying panes and jobs.

Boundaries that matter

No arbitrary shell or keyboard endpoint, automatic approval, game launch, benchmark, recording, driver install, cloud upload or external AI call. Downloads still require provider/account permission. UMM loader injection and existing-mod upgrades are not supplied by the new panel.

Reports retain the original provider's units and definitions. Saved status is not live performance. An interrupted or changed request is refused rather than replayed.

Development and acceptance

The full code and automated tests are included. Validation separates portable Python/Tk tests from unavailable PowerShell/native Windows tests. Windows deployment and live provider transfers remain unverified; Git publication remains blocked.
