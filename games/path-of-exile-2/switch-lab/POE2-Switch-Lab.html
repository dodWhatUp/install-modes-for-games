      New-account test plan and hardware findings

      What is known

      • GGG discloses collecting hardware identifiers and operating-system information.
      • Collecting identity is not proof of hardware-ban enforcement. A current official confirmation of that enforcement was not found.
      • A different Windows version, VM or account is not a proven guarantee of hardware isolation.
      • Solo/SSF still uses the online service. No solo exemption appears in the macro policy.

      Live test status: not run

      A fresh account would need its own game access. A successful session would show function, not ban safety. The attached test plan covers native weapon-set assignment and individually triggered skills; its prohibited-sequence stage is blocked by the PC-protection requirement.

      The included GGG support question is ready for review and has not been sent.

      Development path

      1. Keep skill gems prepared and enable each skill for set I, II or both.
      2. Keep the 13 fixed Azeron skill slots grouped and retain X on #37.
      3. Use a display-only loadout checklist for inventory-only gear/gems.
      4. Connect the display to the existing overlay host after its supported integration and actual game assignments are confirmed.

      Actual equipped skills, compatibility and Spirit/passive changes require character-specific inspection before applying the prepared plan.

      Sources and evidence limits
      • GGG: native skill-to-weapon-set assignment
      • GGG: current Third-Party Policy
      • GGG: hardware, OS and anti-cheat information
      • Current game access and network requirements

      Research reviewed 2026-10-12. No detection threshold or safe delay was established. Local model tests are separate from browser usability and live game acceptance.
