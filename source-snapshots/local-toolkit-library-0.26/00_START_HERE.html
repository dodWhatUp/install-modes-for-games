מה כבר נבנה

חבילה לכל משחקמוסיפים הגדרות, קידוד מקשים, הקשרים, וריאציות ובדיקות — בלי לשנות את המנוע.
מתאם לפורמט חדשממשק SDK מפורש לקוד טקסט שנבדק; חבילת משחק אינה טוענת או מריצה קוד.
כמה קובצי הגדרותבעלות מפורשת, עדיפות בין ברירות מחדל לדריסות, ובדיקת שינוי בכל הקבצים הקשורים.
כלים לצ׳אטשליפה בחלקים, עדכוני טיוטה קטנים ושמירת גרסאות; הצעות בלבד דרך האישורים הקיימים.
החלפה ושחזוראותו מנגנון המקור: גיבויים, תוכנית חתומה, עצירה וביטול מדויק או ממוקד.
מה לא הוכחלא נבדק ב-Windows או במשחק אמיתי; 17 טיוטות מחקר אינן 17 מתאמים מוכנים.

תהליך העבודה

יוצרים טיוטה למשחק → בודקים עותק מקורי → מגדירים שדות והקשרים → מריצים בדיקות החבילה → בוחרים קבצים פעילים במחשב → מכינים תצוגה מקדימה → מאשרים מקומית → מחליפים עם גיבוי. גם בחירה בהגדרה מוכנה מראש עוברת באותו מנגנון.

תוצאה מאומתת מול מה שעוד חסר

472 בדיקות עברו, ובהן 145 בדיקות חדשות. נבדקו קבצים פיקטיביים, תהליכי דמה, ממשק הפקודות, פרוטוקול הצ׳אט וחלוניות Tk בסביבת Linux. המקור של Workbench 0.23 נשאר ללא שינוי.

אין כאן קובצי החלפה למשחקים אמיתיים ואין טענה שהרכיב מותקן אצלך. קבצים בינריים, Registry, שמירות והיררכיות Unreal מורכבות דורשים מתאם ואימות נפרדים.

הפעלה מקומית ומפתחים

נדרש Python 3.10 ומעלה קיים, ולחלונית נדרש Tk. התוכנה אינה מתקינה סביבת ריצה. בניסוי משתמשים בתיקיית נתונים נפרדת, לא מעתיקים הגדרות פעילות אוטומטית.

python scripts/Game-Keybinds.py adapters
python scripts/Game-Keybinds.py pack-check --pack game-packs/format-examples/sample-json
python scripts/Game-Keybinds.py --data-dir YOUR_PREVIEW_DATA gui
