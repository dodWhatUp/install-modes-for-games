# Hogwarts Legacy — Preferences

Last confirmed: 2026-09-02

- Favor high visual quality at 4K with native DLSS and native FG/MFG ownership.
- Keep OptiScaler FG disabled when native Streamline FG is enabled.
- Prefer Ultra Plus as the integrated graphics/performance baseline; do not layer Ascendio, Cinematic Ultra, SLPF, or arbitrary Engine.ini packs over it without an explicit compatibility review.
- Prefer NVIDIA App's named/supported model controls over unexplained numeric preset forcing.
- Preserve the full `WindowsNoEditor` configuration and the shipping-executable directory before updates.
- Put broad gameplay/quest-system mods in a separate profile from graphics debugging.
- If testing RenoDX HDR, create a separate graphics profile from OptiScaler first. Do not assume two ReShade/proxy chains can coexist.
