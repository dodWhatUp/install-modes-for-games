|---|---|---|

| QoL / UI / difficulty | Native Assist Mode vs Custom Mode | Prefer built-in controls for accessibility and run customization; certain custom settings affect progression/achievements as shown by the game |

## Recommended combinations

1. **First playthrough — Core:** native accessibility/Assist options to taste and original progression. Difficulty 1; no mod required.
2. **After familiarity — Strong/Optional:** Custom Mode and one current Workshop cosmetic/balance package. Difficulty 1–2; exact package untested.
3. **Replay — Experimental:** custom-loader multiplayer or broader balance experiments on a copied profile only after selecting a supported release. Difficulty 3–4, Low compatibility confidence.

[Official update announcements](https://steamcommunity.com/app/588650/announcements/) document built-in features; [Custom Mode reference](https://deadcells.wiki.gg/wiki/Custom_Mode) provides further community-maintained detail. Roll back by disabling the chosen Workshop/loader package and restoring the matching pre-experiment save; don't assume unsubscribing reverses progression edits.
