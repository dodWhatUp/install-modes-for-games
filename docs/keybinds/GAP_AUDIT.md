Actual native game field maps and current originals; real Windows process/file ACL,
launcher/cloud behavior and MCP client acceptance; full Unreal list/include graph;
binary/Registry/save-container schema providers; active-instance version migration;
automatic deletion/retention and OS authorization hardening; signed publisher trust;
handheld/mod-manager profile auto-detection. Each requires its own bounded review
and tests. None is implied by a parser's existence, a fixture or an approved draft.

The source and original test history are preserved. Main-repository writes, remote
operations, browser policy blocks and game launches were not retried or bypassed.
