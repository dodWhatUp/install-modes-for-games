# Hogwarts Legacy — Curated Recommendations

## First playthrough

**Core:** current game fixes, native DLSS/FG controls, and either stock graphics or one conservative Ultra Plus profile selected for VRAM. Keep OptiScaler FG disabled when native FG is active.

**Strong for mouse users:** one broom-control mod, after choosing the preferred mapping and preserving `Input.ini`.

**Optional:** Blueprint Apparate only when a chosen QoL mod needs it. Avoid progression, curfew, prison, companion, and spell-unlock changes until the original systems are understood.

## After familiarity

**Strong candidates:** Skip Merlin Trials for repetition, selected Apparate UI/QoL modules, and Lore Friendly Apparition after reviewing known restrictions.

**Optional immersive combination:** Apparate + Night Curfew + Azkaban, with SQL/chunk audit and a separate save snapshot. This is a system-overhaul profile, not a casual drop-in list.

**Optional companion combination:** AnyTimeCompanion plus its current recommended companion dependency. Re-check balance and update compatibility first.

## Post-game

**Strong candidate:** the immersive roleplay system profile and broader traversal/season/world-state mods on a copied save.

**Interesting:** large curated mod guide/collection, but import entries into this catalog and resolve conflicts rather than installing the collection blindly.

## Graphics combinations

1. **Recommended known baseline:** Ultra Plus + native DLSS Balanced + native FG/MFG + OptiScaler neural experiment with OptiScaler FG off. Recommendation **Strong/Conditional**, local confidence **High for the recorded build**, difficulty **3**.
2. **HDR profile research:** current RenoDX Hogwarts profile in its own reversible graphics profile. Recommendation **Experimental until local test**, confidence **Medium upstream**, difficulty **3**.
3. **Ultra Plus + Ascendio:** recommendation **Avoid** because the authors describe overlapping/incompatible engine tuning.
4. **Native FG + forced OptiScaler FG:** recommendation **Avoid** based on local instability and duplicate ownership.
