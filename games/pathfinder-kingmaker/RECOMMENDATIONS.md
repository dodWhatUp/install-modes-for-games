# Pathfinder: Kingmaker Recommendations

Broad review: 2026-09-14. Focused spell-clarity and automation review: 2026-10-12. These are staged choices based on [comparisons](COMPARISONS.md), not a claim of local test success.

## Current clarity and automation choice

1. **Strong for repeated preparation:** retain Unity Mod Manager + Buff Bot as the small starting set; AutoBuff is an alternative for explicitly recorded action sequences.
2. **Strong feature match, conditional for a first playthrough:** Kingmaker Tactics 1.0.1 provides configurable real-time rules. To preserve original information limits, start with party health/buff rules and review presets. The inspected enemy-save/AC targeting reads raw stats rather than only Inspect-discovered information. Tactics is inactive in turn-based mode; offensive area safety is limited.
3. **Optional readability:** native Inspect/font sizing plus UI Extensions only after current-build compatibility is checked. No verified whole-spellbook plain-language rewrite or automatic spell-comparison dashboard was found.

See the [focused comparison and sources](COMPARISONS.md#spell-clarity-and-conditional-automation--reviewed-2026-10-12) for exact limits. Recommendations describe candidate use, not game changes.

## First playthrough — recommended

Unity Mod Manager + Buff Bot after compatibility checks. Start with the smallest supported set. Difficulty and exact conflicts are detailed in the comparison guide; test each added layer before continuing a valued save.

## After familiarity

Selected Bag of Tricks conveniences; Cleaner only for a demonstrated need. Expected benefits are qualitative. Keep alternate file/configuration owners in separate profiles and retain a restore point.

## Post-game / replay / experimental

Call of the Wild and supported flanking rules on a new character. Persistent classes, quests, progression and overhauls need a dedicated new/copy save. No additional purchase is assumed.

## Graphics combination

Use the [graphics/DLSS comparison](COMPARISONS.md) to choose one owner for each upscaler, frame generator and tonemapper. Preserve native features where available. Unsupported SR/RR/FG/MFG/NR stays off; only actual resource/evaluation evidence can establish support.

## Current boundary

Information-only review is complete; no game mutation or test occurred. Rollback cost, conflicts and confidence belong beside the options, not hidden behind a popularity score.
