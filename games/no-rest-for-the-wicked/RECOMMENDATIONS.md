# No Rest for the Wicked recommendations

## First playthrough

**Core UI candidate:** Rune Details. **Strong convenience candidates:** Build
Liberator and Wicked Menu. The selected installation contains these three with
MelonLoader 0.7.3 and private .NET 6.0.36. Difficulty 2, confidence medium from
author documentation and local file checks; combined runtime stability is untested.
Performance/memory overhead has not been measured.

Use a solo realm for initial checks. Keep a verified save backup, and test a
disposable item before extracting from important gear. F12 opens the configured
Wicked Menu. Options > Gameplay > Details Display Mode controls Rune Details.
These tools ease build changes but do not implement the requested independent
spell library. Disable through the file controller after saving/exiting the game.

## After familiarity

Item Manager is optional for build/loadout experimentation and includes cheats.
Inventory Space Increaser is optional for storage convenience; saved capacity and
items need reconciliation before removal. Neither is installed or a substitute
for expanding equipped spell slots. Do not claim direct in-combat loadout keys.

## Replay and experiments

Channel Rune Cost Stamina changes combat balance and needs fresh compatibility
investigation because of its July 2026 bug report. WickedView is an experimental
camera alternative. Visual presets are optional aesthetic changes. Keep each
extension separate and reversible; do not assume the current setup accepts it.
