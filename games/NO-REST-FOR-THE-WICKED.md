# No Rest for the Wicked

Steam early-access game build 29466 / Steam build 22928553 inspected on
2026-10-25. The user confirmed older characters work with this build. Steam
subsequently uninstalled the base game at 20:31 local time; the user reinstalled
it. Steam reports a complete installation of the same public build. Executable
and main assembly hashes match the earlier baseline, 35 save/account-settings
files remain unchanged, and all four mod components retain their owned hashes.

The preserved gameplay setup contains MelonLoader 0.7.3, Build Liberator 1.0.0,
Rune Details 1.1.0 and Wicked Menu 1.0-0225. File switching and the Desktop
control launcher are verified; mod runtime loading and gameplay effects remain
untested. The Classes system is planned for the December 2026 Open Beta and
March 2027 version 1.0, rather than the current public build.

This setup eases rune/build changes. It does not provide 10–20 weapon-independent
spell slots, remove weapon-type restrictions or add a dedicated quick weapon-swap
system. The native weapon cycle and portable rune-management menu remain distinct.

The private installation binding owns exact paths, archives, hashes, save/settings
recovery and receipts. The data-only support pack describes layout, not certified
runtime support or permission to launch the game.
