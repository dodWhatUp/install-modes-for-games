## Read the status correctly

- **Planned:** collected and scoped, not implemented in the current product.
- **Partial:** some implementation or acceptance exists; the stated remainder is not completed.
- **Fixture-tested:** authored source has passed isolated tests. This is not a measured resource result, native-device behavior or live game acceptance.
- **Historical live:** an observed result belongs to the recorded older build/context, not automatically the current version.
- **Owner-reported:** the owning related chat reports a result; its underlying source/bytes/runtime have not been independently audited in this checklist pass.
- **In progress:** this offline build is underway. It must be replaced with a scoped result and evidence before being called complete.

The next-acceptance column identifies work possible **Offline**, work requiring a later explicitly requested **Desktop/device** test, or a later explicitly requested **Game/capture** test. A feature with multiple boundaries uses the lowest applicable status; one successful subtest does not complete the whole row. Missing values remain unavailable/null, not zero.
