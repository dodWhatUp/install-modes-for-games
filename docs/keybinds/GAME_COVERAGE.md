# Honest game coverage

The original 17-game discovery research catalog is retained unchanged in
`examples/keybinds/game-locations.json`. Each corresponding `game-packs/research-drafts`
folder preserves its location evidence and exposes a **draft**, with empty fields,
incomplete inventory and unresolved-native adapter. None is a fabricated game config.

`game-packs/format-examples` contains ten **fictional** formats with executable
fixture checks. These prove file processing, lookup, staging and rollback paths in
this environment. They do not certify any named game. The SDK example adds a
fictional eleventh grammar only when trusted host code explicitly registers it.

To turn one research draft into a supported game pack, use current originals and
`docs/EXTENSION_GUIDE.md`. Keep edition/store/build, exact input mode, native action
IDs and runtime contexts separate. SPARSE6 stays unchanged. Existing Planner V3
source qualifiers and unresolved contexts remain; no native configs were generated
for the 17 games in this development task.
