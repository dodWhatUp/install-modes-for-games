# Keybinds merge limitations

## Not established by this package

- Native Windows launcher, ACL, known-folder and filesystem behavior.
- Installation into the user's production Game Tools profile.
- Live ChatGPT/MCP client transport or provider integration.
- Real-game configuration discovery, mutation, readback or gameplay behavior.
- Physical Azeron behavior, onboard profiles, SPARSE6 output, joystick layers or input injection.
- Registry, binary, save-file or Unreal hierarchy adapters.
- Git publication, Drive delivery, deployment or automatic updates.

## Evidence boundaries

- Linux/Python tests and Tk widgets under Xvfb validate source contracts, not native Windows acceptance.
- Ten included format packs are synthetic fixtures. They prove parser/transaction extension behavior, not support for a named commercial game.
- All seventeen named game folders are research drafts. Location evidence is not a certified active-file detector or native adapter.
- `GameModPanel` timed out in one bounded A-baseline Xvfb run. It was not retried. Other A, B, merged, conflict and post-patch suites listed in the validation record passed.
- PowerShell is unavailable in the packaging environment. Seven installer tests now report an explicit environment skip instead of false execution errors. The exporter and preview launcher are checked statically; final ZIPs are created with a Python equivalent and every entry is independently re-hashed and CRC-checked.
- The revised Windows preview launcher has not been executed on native Windows. Its runtime-probe, shortcut and argument behavior still require native acceptance.
- Interrupted pack imports remain visible as `INCOMPLETE_OR_CORRUPT`; there is no automatic retry, deletion or recovery mutation. This review intentionally did not add one without a bounded recovery contract and native interruption evidence.

## Safety boundaries retained

The component cannot approve its own proposal, silently select an ambiguous profile, replace unrelated settings, run a data-pack as code, launch a game, inject input or claim gameplay success. Drift, revision changes and unknown effects stop the affected operation instead of triggering an automatic alternate path.
