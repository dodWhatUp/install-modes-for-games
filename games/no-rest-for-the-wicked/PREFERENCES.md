# No Rest for the Wicked preferences

- Prioritize access to more magic and combat abilities, including while wielding
  ordinary weapons. The desired target is 10–20 conveniently selectable abilities.
- Preserve the distinction between an independent spell library, native weapon
  cycling, equipment loadouts and rune editing through a menu.
- Gameplay mods need quick all-off/on and individual controls with saved settings.
- The installed menu binding is F12, following the shared engine-menu preference.
- Opening the controller is separate from installing/updating and from Apply.
- Keep small GitHub, Nexus, Preview and Options buttons on each mod's enable row,
  preserving its height. Preview shows the mod description and relevant author
  images. Both previews and options open beside the current mouse position.
- Current install is the three-plugin setup in HISTORY.md. Additional balance,
  item spawning, inventory-capacity and graphics options remain separate candidates.
